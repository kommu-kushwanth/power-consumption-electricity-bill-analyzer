# ⚡ Power Consumption & Electricity Bill Analyzer
A Python-based mini project designed to calculate electrical energy consumption and estimate electricity bills based on household appliance usage.

## 🚀 Features
- Add electrical appliances
- Calculate daily energy consumption
- Calculate monthly energy consumption
- Estimate electricity bill
- Identify the highest power-consuming appliance
- Generate a power consumption report
- Provide basic energy-saving suggestions

## 🛠️ Technologies Used
- Python
- Basic Python programming
- Lists
- Dictionaries
- Loops
- Conditional statements
- Arithmetic calculations

## ⚡ Formula Used
Energy Consumption:
Energy (kWh) = Power (W) × Quantity × Usage Hours / 1000

Monthly Energy:
Monthly Energy = Daily Energy × 30

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project in Python or VS Code.
3. Run `main.py`.
4. Enter the appliance details.
5. Select options from the menu.

## 📌 Project Purpose
The purpose of this project is to combine Python programming with Electrical & Electronics Engineering concepts to analyze household energy consumption and electricity costs.
